# Ask Omkar setup

Ask Omkar is a static-site chatbot with a browser UI in `chatbot.js`, a local editable knowledge base in `data/omkar/knowledge.json`, and a server-side Netlify function in `netlify/functions/chat.js`. It uses Google's Gemini API.

## Configure the AI provider

1. Open [Google AI Studio](https://aistudio.google.com/apikey) and create a Gemini API key.
2. Copy `.env.example` to `.env` for local Netlify development.
3. Set `GEMINI_API_KEY` to the Gemini key stored in your server environment.
4. Optionally set `GEMINI_MODEL`; the default is `gemini-2.5-flash`.
4. Never commit `.env` or put the key in HTML, browser JavaScript, or a `NEXT_PUBLIC_`/client-exposed variable.

On Netlify, add `GEMINI_API_KEY` in Site configuration > Environment variables. The function reads it at request time. Gemini free-tier limits and availability depend on the Google AI Studio account and selected model.

## Run locally

This site has no build step or package manager. To test the function locally, install the Netlify CLI if it is not already available, then run:

```text
netlify dev
```

Open the URL printed by Netlify. The `/api/chat` redirect in `netlify.toml` will route the browser request to the function.

Opening `index.html` directly will still show the portfolio, but the chatbot API requires a local server or deployed Netlify site.

## Edit Omkar's information

Edit `data/omkar/knowledge.json`. Keep claims factual and add information to the relevant section: `profile`, `education`, `experience`, `skills`, `projects`, `philosophy`, `community_and_content`, or `faq`.

Project `anchor` values must match real in-page case-study anchors. Project `url` values should only be added for verified public websites. The function derives action links from an explicit allowlist; it does not trust URLs generated by the model.

## Behavior and security

- The OpenAI key is used only by the Netlify function.
- Messages are limited to 1,200 characters and conversation history is capped.
- A lightweight per-instance rate limit allows 20 requests per minute per forwarded client address.
- The system prompt instructs the model to use only the supplied knowledge base and resist prompt-injection requests.
- The browser renders assistant text with `textContent`; action links are allowlisted before rendering.
- Conversation history exists only in the current page session and is not stored by this project.

## Deployment assumptions

The deployment target is Netlify because the portfolio is static and the repository already contains a `netlify` directory. Netlify must be configured to publish the repository root and use `netlify/functions` as the functions directory; `netlify.toml` contains those defaults.

The AI provider, model pricing, availability, and Netlify environment configuration remain operational responsibilities outside this repository.
